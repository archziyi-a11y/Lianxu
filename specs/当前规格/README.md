## 三条已确认的组织原则

一天包含多轮交流，看板呈现最新有效结果；轮次与来源在内部保留。个人资料、实际记录和助手产物各有持久依据，卡片与模型上下文引用它们。意图规则指导必要信息和合适表达，不固化业务卡片模板。

## 规则地位

产品范围、两页定位、批注与收发动效、日界线及上述三条原则已获用户确认。名称“今日／档案”、六类基础组件、六列实现、数值策略与时间阈值是首版默认或实现方案，未逐项声称为用户共识。视觉和手感参数在原型中调试。
