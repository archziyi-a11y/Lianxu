# 外部智能体接入候选：独立审计交接

状态：本地候选，尚未通过真实 Grok Bot、长期部署与用户真实训练数据验收。它不应被描述为规格 09 的完整验收通过。

## 实现范围

- 额外 Room 表、6→7 迁移、版本化计划、需求、输入队列与单个外部处理方。切换使用代际隔离；运行中与失败的内置输入按原 submission 转交，切回后可由 AgentRunner 接续。
- Python SQLite 桥接与 MCP Streamable HTTP：快照、交接、队列、今日和档案提议、计划与需求、状态查询；图片由智能体明确请求后才上传到服务进程内存。可选 Grok Bot webhook 是触发机制，200 不等于运行完成。
- 今日受限组件：文字、训练/测量等输入、引用现有计算的数值和趋势、选项；支持排列、外部卡删除、分组标签、强调、收起/展开以及用户触发的本机记组和计时。档案沿用既有来源、归档和优先校验。编辑时提议延后、应用时再次检查资料。
- 设置页接入与切回；WorkManager 联网重试；档案计划/需求和声明目标或约束变化时的待决定入口。实际目标变更仍由用户在资料中操作。

## 已知边界和待审计项

- **外部账号和服务未落地**：未配置真实 Grok Bot、真实 webhook、HTTPS 服务或费用；自定义 MCP 的 Bearer 认证在该账号侧是否可配置尚未验证。服务仅监听本机，生产使用还需要用户选择并授权联网服务及安全部署；SQLite 内容无应用层加密。见 `bridge/README.md`。
- **约束语义**：当前目标 ID/修订、来源和显式声明被检查；自由文本限制及未声明的目标变更不能由程序可靠理解，依赖智能体遵守。未实现通用结构化硬约束管理/完整规则校验。
- **交接和决策仍需真机情境验证**：无密钥、离线撤权、后台系统限制、应用被杀、多个连续任务、通知权限和用户实际决策后接续没有全部端到端覆盖。手机离线时远端撤权不能即时到达，平台定时任务须在平台另行暂停。决定记录保存在需求列表，当前同意/拒绝后仍需用户手动更新资料，列表没有完整的决策生命周期界面。
- **组件能力有限**：分组以标签及顺序表达，收起按卡片而非组；low 和 normal 目前没有独立视觉样式。外部只能删除其管理的卡，不能删除固定/本地卡。图片块、任意自定义组件和脚本没有开放。被取消跟进的引用会拒绝，但无法机械识别未关联的同义改写。
- **计划和输入**：明确记组时可绑定当前指定计划；历史或无法确定执行版本的训练保持未关联，尚无完整的历史记录手动选择版本界面。未来计划不会由手机在生效时自动启用，需智能体再次提交启用。需用户决定时发送系统通知依赖系统授权，实际通知行为尚未验证。
- **传输与触发**：全量快照有限额 16 MB，没有分页；图片最大 25 MB。后台周期同步的时机受 Android 调度限制。没有配置 webhook 时依赖 Bot 自己的例程或手动运行。极端崩溃仍可能导致 webhook 重复触发；数据写入以提交 ID 和事务收据去重。尚未对生产公网高并发、安全代理或灾难恢复作完整测试。
