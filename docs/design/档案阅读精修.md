# 档案阅读精修 · 2026-10-28

设计判断：维持纸白/石墨与酸黄主题，以现有排序的第一张有效卡为视觉重点，不另造重要性分数。overview弱化为阅读导语，首卡全宽、较强标题，其余卡保持原跨度。优先展示主题的稳定身份与排序不变。

多指标卡采用主指标和紧凑辅指标组；窄屏、大字体改为单列。所有数值来自原解析结果，不添加推测值。线图提供三条纵轴数值、单位与局部范围说明，范围两端留白，避免把微小变化撑满画幅。训练日历星期和格子共用七等分宽度。

稀疏状态用“记录今天”作为主操作，资料作为次级入口。不绘制无数据图、不要求补齐问卷。卡片直接提示查看依据，长按展示选项继续有效。

隔离样本通过生产MainScreen承载，保留两页指示和安全区。最初before截图使用直接ArchiveScreen夹具，缺少外层容器；仅作定位过程，不作为产品布局的前后比较证据。
