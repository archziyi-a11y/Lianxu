# 第五阶段设计决策

2026-10-25，已实施；实际证据另见第五阶段验收。

已完整读取独立交接与08，检查当前规格和真实实现，并在 emulator-5554 运行原应用。参考 KARAKTER Graphic Realism（https://karakter.de/marathon_new/）的大块几何和标识层级、Marathon 官网（https://marathonthegame.com/）的品牌尺度。Exodus-12 作者页及嵌入播放器已访问，但工具返回播放器 JavaScript 错误，未把未观看的视频描述为已研究的动作依据。Compose 动画官方资料与 ui-ux-pro-max 原生检查项用于实现约束；技能生成的营销页面模板不适用于本产品，不采用。

选择纸白／石墨双主题；酸黄用于统一发送和浅色激活面，正文与小按钮使用深橄榄色确保对比；蓝绿表示补充和依据，橙色留给需注意状态。中文使用 Android 内置无衬线与 Noto CJK 回退，数字使用系统 condensed 字体，离线可用，不复制游戏字体或资产。六列网格保留，窄屏或大字体将卡片扩为整行。今日卡片右上12dp切角、档案6dp圆角，1dp 普通边界、激活 2dp，按钮至少48dp触控。

今日优先给可操作的记录结构。历史动作是候选名称，不带入历史组数或次数；未填写保持未知。本次真实编辑进入持久草稿，同轮统一保存。照片与描述可独立开始。新增组件有可见入口。

批注保持原处：长按激活，出现提示区；点按进入文本编辑，上划提示区切为图片入口，点击选择系统相册。文字/图片按钮提供等效路径，避免与控件滑块、正常纵滚和横滑竞争；关闭只收起，撤掉补充才删除草稿。发送全网格上移260ms，回复从下上移420ms；系统动画缩放为0时 Compose 自动停止大位移，等待状态仍显示。

档案保持阅读、依据与管理职责。资料与目标、全部记录、习惯与跟进为稳定入口；分析历史、历日方案、方法、备份及连接设置可到达。历史补记默认昨天，今日信息引导回今日。归档展示、取消跟进、删除事实互不替代。

持久化复用 KnowledgeNote 的稳定身份、revision、origin、status 和 EntitySnapshot，新增应用专属 kind：follow_up、follow_up_progress、input_habit、method_invitation。不新增表，因此 Room schema6 与原迁移链不变，现有备份自然携带这些记录。卡片新增可选字段有默认值，旧备份可解码。助手 upsert_knowledge 禁止修改这些专属状态。

取消跟进保留墓碑，纳入所有上下文及事务指纹。旧响应因依据变化拒绝提交。为避免模型用改名的新问题绕过取消：出现取消历史后，模型不自动创建新的持续安排，用户在档案明确新建或重新开启；已有仍有效的其他安排继续。此保守边界避免靠相似文本猜用户意愿。

可选问题首轮支持注册测量 series/rolling_mean 方法的一个可补齐测量缺口；与现行目标关联，先用同一执行器验证补一个真实测量日确实能达标。比较口径、分组样本不足不会转成长问卷。每次最多一个方法邀请；略过按方法版本及最近证据保存，证据未变不反复出现。不保存假想测量、不提前发布结果。

实际操作后的调整：营养只读卡去掉重复输入按钮，统一长按激活；输入组件保留可见等效入口。新建入口固定在页头，创建后滚动到新卡。文本用 Compose TextFieldState 即时处理 IME，持久化异步顺序完成；组数与字段也先本地回显，避免数据库回读打断键入。完成图标放在输入框内，键盘打开时页头收紧、隐藏重复提示，消费外层安全区避免重复留白，并将输入框滚入可视区。窄屏日期独立成行，横屏收紧页头。

默认回复移到本轮看板前部，返回时回到顶部；成功摘要由回复卡承载，避免通知区重复全文。真实网络错误仍显示原因并保留旧看板与草稿。系统栏文字颜色随正式主题切换。

营养数值明确标注目标：今日标题包含“目标”，档案营养目标显示“当前目标”，避免把计算目标读成已发生的摄入。丰富看板的新首卡到达也触发回复定位，覆盖数据库推送晚于处理标志结束的时序。
