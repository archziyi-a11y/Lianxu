# 连续使用旅程 · 2026-10-28

本轮围绕训练后补记、同日继续和下次承接，不增加导航页面或静态业务卡模板。

- 新看板先呈现可直接操作的训练与接续入口，再呈现营养目标；有历史表达习惯时仍使用实际历史准备的控件，不带入已完成数值。
- 已有 AI 回复与卡片编排保留。新出现的主动输入放在已有输入区前；用户有未发补充或激活卡时，保留既有卡片相对次序并把新增入口放在后面，避免正在操作的位置跳动。
- 粗略训练回复先说明实际记录和相关未知，不要求补齐资料；只在有明显帮助时邀请一项可选补充，避免列无关营养资料清单。
- 同日新增事实可使旧分析过时。完全继承的旧分析文本块可继续显示既有的“依据已更新”提示，但新建或修改的模型块仍须引用当前有效分析；修订版本仍严格匹配。
- 没有明确卡片 upsert 的回复，将顶层 blocks 放进一张稳定回复卡，避免同轮同时追加 blocks 卡和默认 summary 卡。有明确 upsert 时保留现有协议的编排能力。

真实 API 试跑发现了单轮丰富样本未暴露的问题：第二轮新训练使第一轮分析失效，继承旧块的最终校验阻止新轮提交。该发现转为回归测试；不通过填造事实、放松全部引用校验或把自然语言当作成功事务来绕过。

Terra 参与了只读源码审阅，指出首屏目标优先和新增跟进埋底问题；此次未完成 Terra/Sol 模型对照，也不将整个实现归因于 Terra。
